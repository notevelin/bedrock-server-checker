# Minecraft Bedrock Server Checker

[English version](README.md)

Небольшая асинхронная консольная утилита для проверки сразу многих серверов **Minecraft Bedrock / Pocket Edition**. Для каждого сервера показывает онлайн, максимум слотов и версию игры, сортируя по онлайну. Работает на [mcstatus](https://github.com/py-mine/mcstatus).

## Возможности

- Параллельная проверка любого числа серверов
- Онлайн, максимум слотов и версия
- Сортировка по количеству игроков
- Отдельный список не ответивших серверов с причиной
- Проверка ввода: неверные порты, пустые адреса и дубли пропускаются
- Порт по умолчанию 19132, если не указан
- Можно проверять новые списки, не перезапуская программу

## Установка

```bash
git clone https://github.com/notevelin/bedrock-server-checker.git
cd bedrock-server-checker
pip install -r requirements.txt
```

## Использование

```bash
python check_servers.py
```

Вводи сервера по одному на строку в формате `host` или `host:port`. Пустая строка запускает проверку. После результатов можно ввести новый список; пустой список завершает программу.

```
> play.example.com:19133
> mc.example.org
> 

Сервер                 Онлайн   Макс    Версия
----------------------------------------------
play.example.com:19133    120    500   1.21.50
mc.example.org:19132       34    100   1.21.44

Не ответили:
  dead.example.net:19132: таймаут (сервер не ответил)
```

## Требования

- Python 3.10+
- `mcstatus`

## Примечания

- Bedrock использует UDP (порт по умолчанию 19132). Если сервер не отвечает, проверь адрес и порт и разрешает ли сервер запросы статуса.
- Таймаут на один сервер 5 секунд (`TIMEOUT` в скрипте).
